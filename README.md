# selah-legal

Public legal pages for the **Selah** iOS/Android app, served via GitHub Pages.

- `index.html` — Privacy Policy. This is the URL registered in App Store Connect
  under App Privacy → Privacy Policy URL.

The source of truth for the policy text lives alongside the app in the private
Selah repo (`PRIVACY.md` / `docs/privacy.html`). When the policy changes there,
copy `docs/privacy.html` over `index.html` here and push — Pages redeploys
automatically.
